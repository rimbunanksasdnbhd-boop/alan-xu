# Alan Xu — portfolio v2 (Linear direction)

Static site, no build step: open `index.html` or serve the folder.

- Design system: `DESIGN.md`, the Linear analysis from
  [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/linear.app).
  Dark canvas #010102, one lavender accent #5e6ad2, 12px hairline cards, Inter + JetBrains Mono.
- Content: CV (EN/CN) in `assets/`, EN/中文 toggle via `data-zh` attributes in `index.html`.
- The product "screenshots" are HTML mock-ups with sample data, labelled as illustrations.
- v1 (light, reference-inspired) stays in `../alan-xu-portfolio`.

Deploy: drag the folder into Netlify Drop, or push to GitHub Pages / Vercel as a static site.
